# 星墜ちの巡礼団 — STARFALL PILGRIMS

HD-2D 風の **2〜4人協力型ローグライクアクション**。ブラウザだけで遊べて、ホストが作った **ルームコード** を伝えれば最大3人のゲストが参加できます。

**▶ 遊ぶ: https://raybbb101.github.io/hoshiochi/**

- ドット絵のキャラを、光源ライティング・ブルーム・ティルトシフト（被写界深度）で仕上げた HD-2D 風の画面
- エフェクトはすべて [pixelfx](https://github.com/patch-gg/pixelfx) のコード製ドット絵エフェクト（画像ファイルなし）
- 効果音と BGM もその場で合成

## 遊び方

1. 名前を入れて「ひとりで巡礼する」か「部屋を作る」
2. 部屋を作ると 5 文字のルームコードが出ます。「招待リンク」をコピーして友達に送るか、コードを伝えてください
3. 友達は「参加する」にコードを入れて参加、職業を選んで「準備OK」
4. ホストが「出発する」

3つのエリア（地下墓所 → 氷晶の聖堂 → 星海の頂）を、各エリア **戦闘×4（うち1つは精鋭戦）→ 休息 → ボス** の順に進みます。部屋をクリアするたびに **加護**（強化）を3つから1つ選びます。1回のプレイは 15〜20 分ほどです。

### 操作

| 操作 | キーボード・マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印 | 左スティック |
| 狙う | マウス（動かさなければ近くの敵を自動で狙う） | 右スティック |
| 攻撃（押しっぱなしで連続） | 左クリック / J | X / RT |
| スキル | 右クリック / K / E | Y / LT |
| 回避ダッシュ（無敵時間あり） | Space / Shift | A / LB |
| 奥義（ゲージ満タン） | Q / R | B / RB |
| メニュー | Esc | START |

### 職業

| 職業 | 特徴 | 攻撃 / スキル / 奥義 |
|---|---|---|
| 剣士 | 3段コンボの前衛。攻撃中は被ダメージ -35% | 三段斬り / 旋風斬 / 星断ち |
| 魔導士 | 火球で焼き、氷で止める。元素コンボの起点 | 火球 / 氷華 / 隕石召喚 |
| 銃士 | 連射と爆撃。単体火力と殲滅力 | 連射 / ロケット / 雷撃掃射 |
| 聖職者 | 鎚で殴り、仲間を癒やし、倒れた者を蘇らせる | 聖鎚 / 癒しの環 / 聖柱 |

### 元素コンボ

| 組み合わせ | コンボ |
|---|---|
| 燃焼中の敵に氷（または凍結中の敵に炎） | 蒸気爆発（範囲ダメージ） |
| 凍結中の敵に重い一撃 | 粉砕（ダメージ ×2.5 + 周囲） |
| 感電中の敵に炎 | 過負荷（範囲ダメージ） |
| 聖印の敵を倒す | 裁き（範囲ダメージ + 全員回復） |

仲間と元素を重ねるほど派手に、強くなります。倒れても、仲間がそばに立てば数秒で起き上がれます（部屋をクリアすると全員復活）。

## 爽快感のための数値（`src/data.js`）

数値はすべて `src/data.js` にまとまっています。主な目安:

- 雑魚は 3〜5 発（0.4〜1.2 秒）で倒れる
- ヒットストップ: 通常 50ms / 会心 90ms / とどめ 120ms / 奥義 180ms
- 敵HPは部屋ごとに ×1.12、加護1つで火力はおよそ ×1.15〜1.35。少しずつ敵を上回る
- 人数が増えると敵を硬くするのではなく **数を増やす**（×(1 + 0.4×(人数-1))）。ボスだけHPを ×(1 + 0.75×(人数-1))
- 部屋クリアで最大HPの20%回復

`node tools/sim.mjs all 2` で、自動操作のプレイを画面なしで高速に回して部屋ごとの戦闘時間・被ダメージの内訳を確認できます（`node tools/sim.mjs all 1 4` で4人プレイ）。`node tools/netsim.mjs 4 300` は、4人分のゲームを遅延つきでメモリ上につないで同期を確かめます。

## しくみ

- **通信**: WebRTC（[PeerJS](https://peerjs.com/) の公開シグナリングサーバー）で P2P 接続。ホストが敵・ボス・部屋の進行を計算し、ゲストへ 15 回/秒で状態を送ります。自分のキャラの移動と攻撃の当たり判定は各自の画面で行うので、ゲストでも操作の遅れがありません
- **描画**: 480×270 のドット絵の画面に pixelfx のエフェクトを描き、WebGL2 で光・ブルーム・ティルトシフト・色調補正をかけます
- **キャラ**: pixelfx の 3D 骨格リグ。技のポーズも pixelfx の技（act）の骨格アニメを借りています

## 手元で動かす

ビルドは不要です。静的ファイルをそのまま配信するだけ:

```bash
python3 tools/serve.py
```

http://localhost:8123 を開きます。`tools/duo.html` はホストとゲストを1つのタブに並べる通信テスト用のページです。
